*draft* Draft: a rendered companion for Neovim

Draft keeps Neovim as the editor. It previews LaTeX in a native macOS window.
The fast preview covers common prose, headings, and inline/display math. A
built PDF is authoritative for a manuscript.

*draft-commands*

:Dp  :DraftPreview  :Draft   Toggle preview of the current .tex file.
:Db  :DraftBuild            Build draft/main.tex with latexmk.

Open any .tex file and run :Dp. A draft/main.tex source participates in the
manuscript workflow. Other .tex files can be fragments without a preamble or
PDF build. :Db only builds a file named draft/main.tex. Saving that file
starts a background build. An explicit :Db reports success or a concise
failure in Neovim; successful save builds stay quiet.

*draft-preview*

With Accessibility access, Draft arranges the exact paired terminal and
preview in a 55/45 layout. The shared divider changes the split. Closing
Draft restores prior terminal geometry. The moon/sun titlebar button switches
between remembered light and dark appearances. The red close button is
available; minimize and zoom are disabled. The preview scrollbar is hidden,
but mouse and keyboard scrolling remain available.

A small dot appears only for preview problems. Yellow means unsupported or
questionable fast-renderer syntax; red means a rendering failure. Click it
for details and source jumps. These are not TeX/LSP diagnostics.

*draft-prose*

An explicitly previewed buffer uses wrap, linebreak, breakindent, and
textwidth=0. In Normal mode, j/k follow visual lines without a count; 5j/5k
retain logical-line motion. Existing mappings take precedence.

*draft-navigation*

<C-g>                   Synchronize the other surface to this position.
:DraftFocus             Focus the preview.
:DraftFocusSource       Focus the paired terminal.

<Plug>(draft-sync)          Normal/Visual source synchronization.
<Plug>(draft-focus-preview) Focus Draft from Normal mode.
<Plug>(draft-focus-source)  Focus source from Normal mode.

Draft installs buffer-local Normal and Visual <C-g> mappings for an active
preview if they do not overwrite explicit mappings. Neovim's usual <C-g>
behavior remains in other buffers. Source cursor or Visual selection maps to
the smallest rendered range available. The divider arrows use the same
operations.

The preview has a subtle mark in the left margin for its reading position.
j/k move it by rendered lines; <C-d>/<C-u> scroll half a viewport and update
it; gg/G move to the ends. Mouse scrolling also updates it. Press <C-g> in
the preview to jump to the mapped source position. An actual browser text
selection takes priority and selects the corresponding source range. Clicked
content sets the reading position. <C-w>h focuses the exact paired terminal;
<C-w>l from Neovim focuses Draft.
